# タイトルロゴ比較案

全6案。組み込み image_gen で生成した背景透過PNG。各案と同名のMarkdownに生成プロンプトを保存。B1とB3は追加の輪郭調整を実施し、最終版のPNGを保存。

6案のPNGは `public/images/candidate/` にも保存しています。タイトル画面のURLに `?logo=a1`、`?logo=a2`、`?logo=a3`、`?logo=b1`、`?logo=b2`、`?logo=b3` のいずれかを付けて開くと、同じ背景・表示サイズで候補を比較できます。指定なし、または無効な指定では現在の採用ロゴを表示します。
