# THE LAST BATTALION

Nuxt / Vue / Pinia と Three.js による、人間軍と魔王軍の数千の兵がぶつかり合う戦術級RTSです。
マップ生成・地形描画・カメラ操作・時間（昼夜）は [no-life-king](../no-life-king) と同じ仕組みを使っています。

## 起動

```bash
npm install
npm run dev
```

開発サーバー: http://localhost:8100/

```bash
npm test       # 砦の配置・通行・戦闘シミュレーションの回帰テスト
npm run build # 本番ビルド
npm run preview
```

## 操作

プレイヤーの指示は部隊単位です（兵士一人ひとりには指示できません）。

### 部隊（大隊・中隊・小隊）

兵士は同じ兵種の小隊（歩兵70人・槍兵50人・弓兵60人・騎兵35人・補給兵20人・工兵30人）に属し、陣で隣り合う同じ兵種の小隊が4つまで集まって中隊を組みます。全軍が大隊です。戦場には中隊の旗（例: 1中歩 210 = 第1中隊・歩兵・210人）と小隊の旗（例: 歩3 70 = 第3歩兵小隊・70人）が立ちます。

- 中隊の分け方: 部隊編成で中隊を組めます（兵種を混ぜてよい、下記「部隊編成」）。組まなかった小隊は開戦時、兵種ごとに陣の左から順に並べ、離れた所（両翼の左右など）で区切り、4小隊以下の同じくらいの数に分けます（歩兵6小隊なら3小隊ずつの2中隊）。中隊は軍ごとの通し番号で、組んだ中隊が先です
- 組んだ中隊は陣でもひとかたまりに並びます。中隊の中は横陣の並べ方（槍兵が前、弓兵が後ろ、騎兵が両翼）で、中隊は主な役目の兵種の場所（歩兵か槍兵がいれば前線、なければ弓兵・騎兵・後方の順）に並びます
- 中隊の中の連携:
  - 中隊ごとに移動・攻撃を命じると、行き先（攻撃なら相手）からまだ遠い小隊は、そのうち一番遅い小隊に歩みをそろえます（移動は行き先から40、攻撃は相手から130より近づいたらそろえない）。槍兵と騎兵を組めば騎兵も槍兵の速さで進むので、速さと守りの釣り合いを編成で選びます。中隊の小隊に個別の指示を出すと、その中隊はそろえるのをやめます
  - 弓兵の小隊の75以内に敵の小隊が迫ると、同じ中隊で移動・待機の指示で構えている近接の小隊（歩兵・槍兵・騎兵）のうち、敵に一番近い小隊がその敵を攻撃します
- 増援の小隊は、陣にいる同じ兵種の自動の中隊に空きがあればそこへ加わり、なければ新しい中隊を組みます（組んだ中隊には加わりません）。全滅した小隊は中隊から外れ、小隊がいなくなった中隊は解散します
- 引いた視点では中隊の旗だけを出し、寄ると小隊の旗も出ます（中隊の旗は小さくなります）。選んでいる小隊と、選んでいる中隊の小隊の旗は、引いた視点でも出ます

#### 中隊への指示

- 中隊の旗をドラッグして離す:
  - 地面 → 中隊ごとその地点へ移動して構える。小隊は中隊の隊形（横陣の並べ方: 槍兵が前、弓兵が後ろ、騎兵が両翼）を組み、地点が中隊のまん中になる。向きは進んだ方向（建設中の工兵・補給に当たっている補給部隊・補給中の小隊は今の仕事を続ける）
  - 敵の中隊の旗 → 各小隊が、その中隊のうち自分に最も近い小隊を攻撃 / 敵の小隊 → 各小隊がその小隊を攻撃（補給部隊と工兵は加わらない）
  - 敵の建設物 → 破壊 / 自陣 → 退却 / 敵陣 → 突撃
- 中隊の旗を長押し、または中隊を選んで操作バーから: 突撃・待機・陣形に戻る・退却・補給に戻る（補給部隊のいる中隊は自動補給も）。突撃に補給部隊と工兵は加わりません
- 中隊の旗をクリックすると中隊を選び、中隊のすべての小隊の足元に輪、行き先に矢印が出ます
- 中隊の中の小隊にも、これまでどおり小隊ごとに指示できます（中隊からは外れません。中隊へ指示すると、また中隊でまとまって動きます）。小隊の旗を敵の中隊の旗へドラッグすると、その中隊のうち一番近い小隊を攻撃します
- 部隊一覧（操作バーの「部隊」）は 大隊 › 中隊 › 小隊 の木の形です。中隊の名前で中隊を選び（カメラが寄る）、▸ で小隊を開きます。小隊を選んでいるときは、左上のパネルの中隊名から属する中隊を選べます

#### 小隊への指示

- 部隊の旗をドラッグして離す:
  - 地面 → その地点へ移動して構える（向きは進んだ方向）
  - 敵部隊の旗（または敵部隊の近く） → その部隊を攻撃
  - 敵の建設物 → その建設物を破壊
  - （工兵）川 → そこに橋を架ける / 自軍の建設中・傷んだ建設物 → 続きを建てる・修理する
  - 自陣 → 退却 / 敵陣 → 突撃
- 部隊の旗を長押し: メニュー（待機・突撃・陣形に戻る・退却。弓兵と補給部隊は「補給に戻る」も。補給部隊は突撃の代わりに「自動補給」）。表示中は一時停止
- 部隊の旗・隊長の幟・兵士・部隊一覧をクリック: 部隊を選択（兵の足元に輪、行き先を矢印で表示。左上に部隊の状態、画面下の操作バーにその部隊への指示が出る）

| 指示 | 動き |
|---|---|
| 陣形 | 全軍の陣形の持ち場につく |
| 移動・待機 | 指定地点・その場で隊列を組んで構える |
| 攻撃 | 指定した敵部隊を追って戦う |
| 突撃 | 各兵が自由に戦いながら敵本陣へ向かう |
| 退却 | 自陣まで下がり、正門の内側で構える |
| 補給に戻る（弓兵・補給部隊） | 自陣の陣地まで戻って矢を補充し、補給前の指示に戻る |
| 建設（工兵） | 拠点・バリケード・橋を建てる。操作バーか長押しメニューで選び、地面をクリックして場所を決める（緑なら置ける。R でバリケードの向きを変える、Esc で取り消し） |
| 破壊 | 指定した敵の建設物を壊す |
| 自動補給（補給部隊） | 矢の減った弓兵の部隊を探して矢を届ける。補給部隊の旗を味方の弓兵部隊の旗へドラッグすると届け先を指定 |

持ち場のある指示（陣形・移動・待機）では、兵は持ち場の近くに来た敵とだけ戦い、離れすぎたら持ち場へ戻ります（歩兵45・槍兵8・騎兵80・弓兵は射程まで）。

### 全軍の陣形

- 操作バーの「全軍」、または「全軍」の旗の長押しで陣形を選ぶ: 横陣・鶴翼・魚鱗・方円・鋒矢。選ぶとすべての部隊が陣に戻ります
- 「全軍」の旗をドラッグ: 陣全体を移動（向きは敵軍の方）
- 全軍突撃・全軍待機・全軍退却（陣形と同じメニューから）
- 増援の部隊は陣に加わります

### 視点

- 何もない場所から左ドラッグ: 視点回転 / Shift＋左ドラッグ・右ドラッグ・中ボタンドラッグ: パン / ホイール: 拡大縮小
- トラックパッド: 2本指の横ドラッグで左右回転、縦スクロール・ピンチで拡大縮小
- タッチ操作: 何もない場所から1本指でパン、2本指の横ドラッグで左右回転、ピンチで拡大縮小
- 「視点」: 戦場全体を見渡す初期視点に戻る

### 画面

- 上: 両軍の兵の総数と本陣の耐久、中央に時刻。兵数にマウスを乗せる（タップする）と兵種ごとの内訳・予備兵・撃破数
- 画面下の操作バー: 左は選んでいるものへの指示（部隊を選んでいなければ「全軍」）、右は「部隊」（部隊一覧の開閉。兵種ごとにまとめて表示し、矢・体力・補給が心もとない部隊のいる兵種に ⚠）・停止 / 再開・速度（押すたびに ×0.5 / ×1 / ×2 / ×3）・視点・メニュー
- 操作バーの上の一言: その場でできる操作（ドラッグ中は離したときの指示、建設中は置き方）
- メニュー: 戦場（モード・地形・SEED のコピー）、戦況の詳細、陣営の特徴、操作説明、タイトルへ戻る
- Space: 一時停止・再開（停止中も指示できます） / Esc: ドラッグ・建設の取り消し、メニューを閉じる

## ルール

- 戦場の左側に人間軍、右側に魔王軍の砦（ベースキャンプ）があります。砦は地形を見て、両軍の距離が離れすぎないように置かれます（端から少し内側に寄ることもあります）。敵の本陣（司令天幕）の耐久を0にした軍の勝利です。
- 開戦時、両軍は砦の前に横陣で布陣します（歩兵6・槍兵3・弓兵5・騎兵4・補給2・工兵2部隊、計1,110人）。人間軍の編成は戦場に入ってから部隊編成で決めます（下記「部隊編成」）。
- 砦は9秒ごとに1部隊の増援を兵舎・厩舎から送り出します。予備兵は各軍2,500人（既定の編成のとき）で、尽きると増援は来ません（最後の大隊）。同時に戦場に出られるのは各軍1,600人までです。
- 砦の物見櫓は近づいた敵を射撃します。

### 部隊編成

タイトル画面で「開戦する」（またはSEEDを指定して開始）を選ぶと戦場に入り、開戦前（時間は止まったまま。部隊への指示はできないが、視点は戦闘中と同じ操作で動かせる）に画面右の部隊編成で人間軍の編成を決めます。編成を変えるとその場で戦場の布陣に映り、「開戦する」で戦いが始まります。編成は戦場の種類ごとにブラウザーに残り、次回はそこから始まります（勝敗後の Restart は同じ編成ですぐ開戦）。「戻る」でタイトル画面に戻ります。

- 開戦時の陣: 横陣・鶴翼・魚鱗・方円・鋒矢から選ぶ
- 中隊を組む: ひな形（混成＝槍・歩・弓、槍弓＝槍・槍・弓、歩兵＝歩×3、弓兵＝弓×3、騎兵＝騎×2、騎弓＝騎・弓）から中隊を加え、中隊ごとに小隊を加え・外し・人数を変える（1中隊4小隊まで、20中隊まで）。「解く」で中隊の小隊を自動の中隊の側へ戻す
- そのほかの小隊: 兵種ごとに小隊を加え・外し（中隊を組んだ小隊も含めて兵種ごとに20小隊まで）、1小隊の人数を10人〜定員の2倍で決める。陣では同じ兵種の小隊が横に10まで並び、超えた分は後ろの2列目に並びます（後ろの兵種はその分下がります）
- 部隊の人数は軍の兵（攻防戦3,610人・防衛戦2,310人・攻城戦2,500人）から割り当て、残りが砦の予備兵（増援）になります。開戦時に布陣できるのは1,600人まで（攻城戦は2,500人まで）。攻城戦の人間軍は増援がないので、割り当てなかった兵は戦場に出ません
- プリセット: 標準（既定の編成）・堅陣（方円）・弓兵重視（横陣）・騎兵重視（鋒矢）・混成中隊（横陣）。堅陣・弓兵重視・騎兵重視は既定の編成と同じ人数で兵種の割合を変えます。混成中隊は槍・歩・弓の中隊3つ、歩兵中隊、弓兵中隊、騎兵中隊2つを組み、補給兵と工兵は自動の中隊にします（増援のない攻め手は中隊の数を増やします）

### 戦場の種類

タイトル画面で選びます。

| 種類 | 内容 | 勝利・敗北 |
| --- | --- | --- |
| 攻防戦 | 両軍が砦を持つ（上記のとおり） | 敵の本陣を落とした軍の勝利 |
| 攻城戦 | 人間軍が魔王軍の砦を攻める | 人間軍は本陣を落とせば勝利、全滅で敗北 |
| 防衛戦 | 魔王軍の攻勢から人間軍の砦を守る | 人間軍は敵を全滅させれば勝利、本陣を落とされれば敗北 |

- 攻城戦・防衛戦の攻め手は砦を持たず、増援もありません。敵の砦の正門から約520px離れた開けた場所に布陣し（歩兵10・槍兵4・弓兵8・騎兵6・補給3・工兵3部隊、計1,740人）、陣の後方の野営地へ退却・補給に戻ります。
- 攻城戦・防衛戦の守り手の砦は、岩山の城（24×28マス）です。周りを城壁と塔が一周して囲み、斜面には家並みと林があります。門は前面の正門ひとつで、門の内の広場から家並みの間を巻いて登る大通りと、城壁沿いを回って登る道の二筋が、頂の本陣を囲む前庭へ通じます。坂では足が遅くなります。本陣には前庭から攻撃できます。
- 守り手の予備兵は1,200人（既定の編成のとき）です。攻城戦で砦を守る魔王軍は打って出ず、陣や砦に迫った人間軍の部隊を迎え撃ちます。
- 魔王軍はCPUの指揮官が部隊単位で指示します（陣を組んで待ち、時機を見て全軍突撃。消耗した部隊は下げ、立て直して再突撃）。

### 地形

攻防戦ではタイトル画面で地形を選びます。攻城戦は魔王城付近、防衛戦は標準の地形で戦います。同じSEEDと地形の組み合わせなら同じ戦場になります。地形の違いは見た目と地形の形だけで、移動や戦闘のルールは変わりません（坂で遅くなる、川を歩いて渡ると遅くなる、林が矢を防ぐ、はどの地形でも同じ）。

| 地形 | 内容 |
| --- | --- |
| 標準 | 森と山があり、川が1〜2本流れる |
| 草原 | なだらかな丘が続き、小さな木立が点在する。川はない |
| 砂漠 | 一方向に並ぶ砂丘が続く。川はなく、ヤシに囲まれたオアシス（池）が1〜2か所ある |
| 荒野 | 起伏が少なく、枯れ木と岩が散らばる。川は0〜2本。遠くには頂の平らな台地 |
| 魔王城付近 | 焦げた荒れ地に枯れ木と黒い岩。川が1〜2本流れ、周りを尖った岩山が囲む。昼は暗く赤みがかった空、夜は赤黒い空に赤い月 |

| 兵種 | 人間軍 | 魔王軍 | 特徴 |
|---|---|---|---|
| 歩兵 | 剣と盾の歩兵 | オーク歩兵（斧） | 近接戦の主力 |
| 槍兵 | 長槍と大盾の槍兵 | オーク槍兵（骨の穂先の長槍） | 前線を守る壁。足は遅い（歩兵の6割）が、受けるダメージは0.6倍で、長い槍で間合いの外から突く。騎兵の突撃が効かない。下記「槍兵の隊列」 |
| 弓兵 | 弓兵 | ゴブリン弓兵 | 射程120前後。近づかれると下がって距離を取る |
| 騎兵 | 槍騎兵 | 狼騎兵 | 高速。走り込んでの初撃は2.6倍（突撃）。弓兵を優先して狙う |
| 補給兵 | 補給兵（矢束の背負子） | ゴブリン運び手（大袋） | 攻撃力はごく低い。前線の弓兵に矢を届ける |
| 工兵 | 工兵（大槌と丸太） | オーク工兵（つるはし） | 拠点・バリケード・橋を建てて直す。建設物を壊すのが得意（3倍） |

### 槍兵の隊列

- 槍兵は移動中も隊列を崩しません。部隊は進む方向を向いた横隊（12人×5列）を組み、隊列ごと行き先へ進みます。兵は隊列の中の持ち場に付いて歩きます
- 隊列は兵が付いて来られる速さで進み、遅れた兵が出ると歩みを緩めます。大きく向きを変えるときは止まって向きを変え、後ろへ向き直るときはその場で回れ右をします
- 槍の穂先は、進むときは進む方向へ、戦うときは攻撃する相手へ向けます
- 味方は槍兵の隊列をすり抜けられますが、敵は槍の間合いへ踏み込めず、隊列を押し通れません（槍兵は敵に押されません）
- 攻撃を命じても隊列を保ったまま相手の部隊へ押し出します。突撃・退却・補給に戻るときは、ほかの兵種と同じく各自で動きます
- 全軍の陣形では最前列に並びます（方円では歩兵と交互に円陣を組み、鋒矢では最後尾を守ります）

### 工兵の建設物

| 建設物 | 大きさ | 建設時間の目安（工兵1部隊30人） | 耐久 | 効果 |
|---|---|---|---|---|
| 拠点 | 7×7マス（砦は12×16マス）。柵で囲み四方に門 | 約2分（作業量3600） | 5000 | 補給できる（矢・体力・補給部隊の補給回数） |
| バリケード | 5マスの柵（南北・東西） | 約10秒（作業量300） | 1500 | 通れなくなる |
| 橋 | 幅2マス・長さ9マスまで | 床1マスあたり約6秒（作業量180/マス） | 2500 | 川を渡れるようになる |

- 作業量は工兵1人が1秒で1。複数の工兵部隊で同じ建設物を建てると早く終わります。建設中は敷地が所属色で示され、部材が順に立ち上がります。地形に効くのは完成してからです
- 建設物は敵味方とも攻撃できます（剣・斧は0.5倍、矢は0.2倍、工兵は3倍）。完成した敵の柵に阻まれた兵は自分から柵を壊しにかかり、「破壊」を指示すれば橋や建設中のものも狙います。壊れると地形は元に戻り、壊れた橋の上の兵は川に落ちます
- 工兵は傷んだ自軍の建設物を修理できます
- 「補給に戻る」部隊（自動で戻る場合も）は、自陣の砦より近い完成した自軍の拠点があればそこで補給します
- マップに元からある橋は壊せません
- 魔王軍の工兵は陣の前に拠点を築き、その前にバリケードを2つ並べ、傷んだ建設物を直します

### 矢と補給

- 弓兵は1人30本の矢を持ち、1回の射撃で1本使います。矢のない弓兵は射撃できません。
- 部隊の矢の残りが5%以下になると、部隊ごと自陣へ戻って補給し、8割5分が満タンになったら補給前の指示に戻ります。砦の中心から170px以内（門の前の陣地を含む）に戻れば受け取れ、受け取った兵はその場で待ちます。
- 補給部隊（20人、1人90本）は既定で「自動補給」につき、矢が6割を切った弓兵の部隊のうち、矢が少なく近い部隊の後ろに付いて矢を渡します。運ぶ矢がなくなったら自陣で積み直して再び出ます。届け先がなければ陣の後ろに控えます。
- 補給部隊は陣形の変更や全軍突撃には加わらず、補給を続けます（全軍待機・全軍退却には従います）。
- 旗には矢の残り（例「矢62%」）か「補給中」が、部隊一覧と部隊パネルには矢の残量が出ます。

### 兵士の判断

兵士は一人ずつ独立して、0.2〜0.5秒ごと（個体差あり）に周囲を見て行動を決めます。

- 視界内の敵から狙う相手を選び、近接兵は経路を離れて直進して斬りかかり、弓兵は射程に入ると射撃します
- 部隊の指示に従いつつ、狙う敵は各自で選びます。突撃中は敵本陣へA*経路で進軍し、軍が一列縦隊にならないよう横の広がりを保って進みます
- 突撃中の兵は、自陣に敵が侵入すると引き返して守ります
- 傷つき劣勢だと、臆病な個体から退却し、しばらくして戦線に戻ります（部隊から離れるほどには退きません）

### 隊長と幟

- 各部隊には自軍の幟を背負った隊長がいます。隊長は退却しません
- 兵は隊長から一定の距離（隊列の対角線＋敵を追う範囲＋40px）より離れません。離れた兵は敵に構わず隊長のもとへ戻り、十分近づいたら戦いに戻ります。隊長から遠い敵は追いません
- 隊長のもとへ戻る兵が部隊の4分の1を超えると、隊長は（戦っていなければ）足を止めて待ちます
- 隊長が倒れると、その場に最も近い兵が幟を引き継ぎます
- 柵や川に阻まれたら、A*で迂回します

### 移動（no-life-king から踏襲）

- 速度 = 兵種の基本速度 × 地形倍率（低山0.5・高山0.35・森0.85/0.7）× 時間帯倍率
- 経路はno-life-kingのA*と同じコスト（8方向・斜め1.414・角の水を跨がない）。数千人で共有するため、敵本陣など戦略目標への経路は目標ごとに累積コストを一度だけ計算し、各兵士はそこから即座に経路を得ます。臨時の目的地には `findPath` を回数制限付きで使います
- 川は橋でしか渡れません。描画上の川岸が水面下になるマスも水として扱います

### 時間

no-life-kingと同じく実時間1秒＝ゲーム内30分で、6:00に始まります。時間表示（`TimePlate.vue`）はno-life-kingからそのままコピーしています。

| 対象 | 移動速度 | 被ダメージ |
|---|---|---|
| 昼の魔王軍 | ×0.6 | ×1.5 |
| 夜の人間軍 | ×0.75 | ×1.3 |

## 構成

- `app/game/` — マップ生成・地形コスト・A*（no-life-kingからコピー）、砦の配置と建設物による地形の置き換え（`playableArea.ts`）、砦のレイアウト（`fortLayout.ts`）、建設地の決定（`construction.ts`）、戦闘シミュレーションと部隊への指示（`battle.ts`）、部隊の隊列と陣形（`formation.ts`）、魔王軍の指揮官（`cpuCommander.ts`）、経路共有（`pathService.ts`）、近傍検索（`spatialHash.ts`）、兵種の数値（`battleConfig.ts`）
- `app/render/three/` — 地形・森・景観・空（no-life-kingからコピー）、砦のモデル（`fortCamp.ts`）、兵士のモデル（`unitModels.ts`）、兵士と矢のインスタンス描画（`army.ts`）、工兵の建設物（`constructions.ts`）
- `app/render/gameScene.ts` — シーン・カメラ・照明・部隊の旗・入力・ゲームループ
- `app/composables/useBattleInput.ts` — 部隊・全軍への指示の入力（no-life-kingの `useGameInput` の作法を踏襲）

兵士は部位（胴体・両脚・武器・騎獣の前脚/後脚）ごとの結合ジオメトリをInstancedMeshで描き、数千人でも描画呼び出しは数十回に収まります。数千の兵士を含む戦闘状態はリアクティブにせず、画面の集計値だけを0.25秒ごとにストアへ反映します。
