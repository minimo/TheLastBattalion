# 人間軍弓兵の作り直し

青いフード、革の胴当て、短い肩布、背中の矢筒を持つ軽装の射手をBlenderで作成した。左手を前へ伸ばして弓を支え、右肘を外へ張って右手を頬の近くへ引く構え。弓の握り・弦の引き位置・矢を同じ照準面に配置している。人間軍の弓兵に適用し、ゴブリン弓兵は従来のモデルと動作を維持する。

| 部位 | 三角形数 |
|---|---:|
| 腰・胴・頭・矢筒 | 251 |
| 左脚 | 68 |
| 右脚 | 68 |
| 構えた腕・弓（攻撃時のみ） | 131 |
| 携えた腕・弓（通常時のみ、合計に含めない） | 106 |
| つがえた矢 | 20 |
| 合計 | 538 |

旧モデルの624三角形から86三角形（約13.8%）削減。描画頂点は882。5部位のインスタンス描画、縮尺0.43、共有マテリアル、距離による影の切り替えを維持し、質感は共通テクスチャ（unit-textures.md）を使う。色は線形色空間の頂点カラーで、フードと裾には陣営色の係数0.65を適用する。大量配置時の実測性能は未確認。

## 構えとアニメーション

通常時は弓を左手で体の横に携え（`carry`）、攻撃時だけ弓を引いた構え（`weapon` と `nock`）に切り替える。胴と頭は `body` で共通。画面に出るのはどちらか一方なので、表示される三角形数は最大538で増えない。非表示の部位は大きさ0のインスタンスとして描かれ、頂点処理の負荷だけが残る。

構えた腕・弓・矢は肩の高さのピボット `[0, 12.3, 0]` で一緒に回るので、照準を変えても手と弓が離れない。見た目の仰角は最大0.55ラジアン（約32度）で、飛翔する矢の弾道計算は変更していない。弓と矢は右頬の横（X=1.0）に通し、引き手の前腕が顔の前を横切らないようにしている。ゴブリン弓兵も同じ仕組み。

## 編集用ファイル

- `assets/blender/human-archer.blend`：`TLB Archer Study` シーンにモデル・照明・カメラを保存。既存の歩兵シーンも保持。
- `app/render/three/assets/humanArcher.json`：ゲーム用の位置・法線・色パレット・インデックス。
- `app/render/three/unitAsset.ts`：全兵種共通の読み込み処理。
- `scripts/blender/refine-archer.py`：モデルの生成スクリプト。**生成シーン内の編集を置き換えるので、通常の再書き出しには使わない。**

## 編集後の再書き出し

`Archer Refined` の子である5部位を編集し、`tlb_role` と `game_pivot` のカスタムプロパティを維持する。上半身と矢の回転をゼロに戻した中立姿勢で保存する。BlenderのZ上方向をゲームのY上方向へ変換して書き出す。

保存後、BlenderのPython Consoleで実行する。

```sh
Blender assets/blender/human-archer.blend --background --python scripts/blender/export-unit.py -- --scene 'TLB Archer Study' --output humanArcher --max-triangles 539
```

書き出し時に5部位・ピボット・縮尺・624三角形以下・有限の頂点値・縮退していない三角形を確認する。照明とカメラはゲーム用データに含めない。

## 確認状況

Blenderでモデルと仰角を付けた構えを確認し、プレビューを保存した。ゲーム内のテスト・ビルド・大量配置の性能測定は、ユーザーが担当する方針に従い実行していない。
